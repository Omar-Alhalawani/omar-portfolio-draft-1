Curve Fitting & Data Visualization App

Python/NumPy toolkit for regression, histograms, and engineering dataset exploration.

This project is a command-line driven tool that lets users load datasets, perform polynomial regressions, generate histograms, and export plots with minimal manual effort. It’s tailored for quick analysis of lab and course data.

The app supports both interactive TextUI and BatchUI modes. In BatchUI, users can define operations in a file and run them in one shot, reducing repetitive typing during analysis.

Project Info

  • Tech: Python, NumPy, Matplotlib
  • Features: Regression, histograms, file-based workflows
  • Year: 2025

Highlights

  • Polynomial fitting with configurable degrees and goodness-of-fit reporting.
  • Histogram generation for quick distribution checks.
  • Batch mode that reduces manual input time by ~70% for repeated analyses.
  • Documentation and example scenarios for reproducible workflows.

Why It Matters

Many student and lab workflows suffer from repetitive, manual plotting. This app turns plotting into a more automated, scriptable process while still being easy to use.
