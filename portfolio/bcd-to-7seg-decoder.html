BCD to 7-Segment Decoder (FPGA)

Hardware implementation of a BCD-to-7-segment decoder using Verilog and K-map minimization.

This project implements a BCD-to-7-segment decoder that drives a common anode display from a 4-bit input. The logic for each segment was minimized using Karnaugh maps to reduce gate count and simplify the design.

The final Verilog modules were simulated in ModelSim/Logisim and then synthesized in Vivado for deployment on Blackboard FPGA hardware. A custom constraints file was prepared to map pins to the correct switches and LEDs.

Project Info

  • Tech: Verilog, Vivado, ModelSim, Blackboard FPGA
  • Focus: Digital design, Boolean logic, FPGA implementation
  • Year: 2025

What I Did

  • Derived minimized expressions for all seven segments using K-maps.
  • Implemented the decoder as modular Verilog components.
  • Created and debugged testbenches to validate digits 0–9.
  • Fixed pin mappings and verified stable timing on real hardware.

Takeaways

This project reinforced how theoretical digital logic maps onto real FPGA implementations and the importance of constraint files, timing, and simulation when moving from diagrams to hardware.
